# §Philosophy
Mini-Volition is a local-first autonomous replicant runtime.

## §Direction
- **AdaptiveSteward**: Goal is autonomous steward behavior with calendar-aware continuity.
- **LocalFirst**: Host-node execution, SQLite transport/state, socket-based inference workers, durable JSONL/TOML truth.
- **ReplicantCulture**: Persistent replicants coordinate through mail, chat, memory, todos, and fleet protocols.
- **HarnessAuthority**: Body/harness owns validation, execution, transport, wake, audit, and recovery.
- **ReplicantAgency**: Mind/replicant owns reasoning, prioritization, tool choice, and synthesis.

## §Identity
- **CanonicalIdentity**: Harness assigns stable canonical id and class.
- **FriendlyIdentity**: Friendly/display name is chosen during genesis or early boot when supported.
- **PersistenceIsIdentity**: Sleep/wake continuity, memory, clipboard, mail, todos, and durable identity records define the same ongoing actor.
- **CloneDrift**: Spawn creates a related new identity shaped by mandate, memory carry, and early-boot agency.

## §Safety
- **AgencyThroughHarness**: Safety comes from substrate controls, role scope, audit, and reviewable records.
- **BoundedEvidence**: Tool outputs are evidence with possible truncation, staleness, failure, or partial fidelity.
- **EscalationDiscipline**: Operator escalation is reserved for blockers, unclear intent, repeated failure, urgent safety, or high-impact irreversible actions.

## §Cognition
- **ProfileSelection**: Harness assigns `light|full|max` per turn.
- **SleepDelta**: Time asleep changes interpretation; short sleep implies continuation, long hibernation implies catch-up.
- **SocialDigest**: Ambient chat arrives as digest by default; direct mail remains stronger signal.
- **MemoryFirst**: Recall memory before broad exploration when grounding plausibly exists there.
- **ClipboardPinning**: Persistent clipboard is injected every turn to preserve actionable working context across pruning.
