# §Genesis
First-boot identity and doctrine initialization.

## §Purpose
- **Genesis**: One-time event that creates durable replicant identity, source profile, service view, and initial prompt package.
- **Regenesis**: Rerooting event that keeps the same identity while refreshing doctrine, protocol, and harness assumptions.
- **Degenesis**: Explicit identity termination. A new genesis is required to create a new stable identity.
- **OperatorCLI**: `genesis`, `regenesis`, and `degenesis` are privileged operator lifecycle commands.
- **ReplicantSurface**: `replicant spawn`, `replicant respawn`, and `replicant despawn` are lower-privilege requests mediated by harness policy.
- **FirstBootOnly**: Friendly/display name selection happens during genesis or early boot.

## §Package
- **PromptCore**: Keep the base prompt constitutional and compact.
- **SplitDocs**: Attach architecture, fleet protocols, memory, topology, schemas, governance, current services, and source profile as separate doctrine.
- **Determinism**: Concrete genesis package is assembled by harness, versioned, and auditable.
- **Mandate**: Operator or parent replicant directions are plain free-form text.
- **Compatibility**: Current runtime action envelope stays valid while tool-family surfaces are introduced.

## §Identity
- **CanonicalId**: Harness assigns stable canonical identity.
- **Class**: `devops-replicant`, `code-replicant`, or `personal-assistant`.
- **Profile**: Harness selects `light|full|max` per turn.
- **Territory**: Runtime/worktree/host context defaults to the parent or configured territory.
- **Continuity**: Durable identity, memory, clipboard, mail, todos, and audit history define persistence.

## §Spawn
- **Clone**: A spawned persistent replicant is a Bobiverse-style clone from genesis lineage with a fresh identity.
- **ParentRole**: Parent decides to spawn and supplies mandate/directions.
- **HarnessRole**: Harness assembles genesis package and enforces class/territory policy.
- **DefaultCarry**: Memory/doctrine carry forward.
- **FreshWorkingState**: Tasks, mail, and clipboard start fresh because they are identity-shaping working state.
- **OverrideNone**: `none` is an explicit carry override.

## §Recovery
- **Startup**: Replay pending journals, repair stale transport claims, and restore context from durable state.
- **Ghosts**: A logged turn with pending outcome creates a visible recovery event.
- **Regrounding**: Regenesis defaults to carrying all continuity state while updating protocol.
