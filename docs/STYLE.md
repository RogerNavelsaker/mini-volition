# §StyleGuide
TDD (Token Dense Dialect) requirements for all `docs/` files.

- **§Sections**: Use section headers for categorization.
- **∂Delta**: Describe changes/transitions.
- **τType**: Data types, protocol signatures, schemas.
- **→Target**: Logic sinks/destination.
- **↑Escalation**: Triggers/paths.

**Rules**: No filler/articles; use bullets; maintain 1:1 parity with turn prompt injection.
